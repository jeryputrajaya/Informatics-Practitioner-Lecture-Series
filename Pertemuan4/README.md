## Deskripsi Ringkas Studi Kasus
Proyek ini membandingkan implementasi dua pendekatan utama *Machine Learning* (*Data-Driven Approach*): **Supervised Learning** (Klasifikasi Kelulusan dengan *Decision Tree*) dan **Unsupervised Learning** (Segmentasi Pola Belajar dengan *K-Means Clustering*).

### Poin Utama Implementasi ML (Pertemuan 4):
1. **Data-Driven Thinking:** Perubahan dari logika *rule-based* konvensional ke pembelajaran berbasis pola data.
2. **Supervised Learning:** Pelatihan model berbasis data berlabel untuk tugas prediktif klasifikasi kelulusan.
3. **Unsupervised Learning:** Pengelompokan data tanpa label (*clustering*) berdasarkan kemiripan pola data fitur.
