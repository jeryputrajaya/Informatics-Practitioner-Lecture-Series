# PERTEMUAN 1: Make Sense of Data with Analysis and AI - Andria Arisal

Repositori ini disusun untuk memenuhi **Tugas Kuliah Praktisi Informatika Universitas Bengkulu**.

## Detail Pertemuan
* **Pertemuan ke:** 1
* **Topik:** Make Sense of Data with Analysis and AI
* **Narasumber:** Andria Arisal, S.T., M.Eng. (Peneliti Senior BRIN)

## Deskripsi Ringkas Studi Kasus
Proyek ini mengimplementasikan tahapan **CRISP-DM** (*Cross-Industry Standard Process for Data Mining*) dalam memprediksi kelayakan pemberian kredit nasabah bank berbasis *Machine Learning*.

### Alur Kerja CRISP-DM (Pertemuan 1):
1. **Business Understanding:** Menentukan kelayakan kredit otomatis untuk mengurangi risiko *non-performing loan*.
2. **Data Understanding & Preparation:** Menyiapkan fitur (Usia, Pendapatan, Beban Hutang, Skor Kredit) dan melakukan *feature scaling*.
3. **Modeling:** Menggunakan algoritma *Random Forest Classifier*.
4. **Evaluation:** Evaluasi performa model menggunakan *Accuracy Score* dan *Confusion Matrix*.
