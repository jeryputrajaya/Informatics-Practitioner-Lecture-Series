## Deskripsi Ringkas Studi Kasus
Proyek ini mensimulasikan implementasi komputasi berkinerja tinggi (*High-Performance Computing* / HPC) untuk menyelesaikan tantangan lokal berupa pemrosesan data cuaca berukuran besar (*Big Data*) secara cepat guna pemetaan potensi bencana.

### Poin Utama Implementasi HPC (Pertemuan 2):
1. **Parallel Computing:** Membagi beban kerja pemrosesan data ke seluruh *core* CPU secara *multi-threading*.
2. **Benchmark Execution:** Mengukur dan membandingkan durasi eksekusi antara pemrosesan sekuensial (*single-core*) dengan pemrosesan paralel (*multi-core*).
3. **Speedup Analysis:** Menghitung skor efisiensi dan akselerasi komputasi berbasis jumlah *core* yang digunakan.
