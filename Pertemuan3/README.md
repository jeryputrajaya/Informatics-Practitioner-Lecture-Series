## Deskripsi Ringkas Studi Kasus
Proyek ini mengimplementasikan konsep Sistem Informasi Geografis (GIS) dan pemrosesan data spasial berbasis Python untuk analisis manajemen aset kota (*asset & property management*) serta pengenalan dasar *spatial proximity*.

### Poin Utama Implementasi GIS (Pertemuan 3):
1. **Spatial Data Management:** Mengolah atribut koordinat geospasial (Latitude, Longitude) dan metadata aset.
2. **Data-Driven Decision Making:** Melakukan kueri pemfilteran otomatis untuk menentukan aset publik yang memerlukan perbaikan berdasarkan skor kondisi fisik.
3. **Spatial Proximity Analysis:** Menghitung estimasi jarak spasial antar-lokasi fasilitas publik.
